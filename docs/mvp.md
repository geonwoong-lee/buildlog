# BuildLog MVP

## 1. BuildLog는 어떤 서비스인가요?

BuildLog는 공부하면서 생긴 기록을 한곳에 모아두는 개인용 웹사이트입니다.

메모장과 AI 대화 등 여러 곳에 흩어진 내용을 다시 찾기 어려운 문제를 해결하려고 만듭니다. 사용자는 오늘 공부한 내용, 앞으로 할 일, 오류와 해결 방법을 저장하고 나중에 검색해서 다시 볼 수 있습니다.

## 2. MVP란 무엇인가요?

MVP는 **실제로 사용할 수 있는 가장 작은 첫 번째 버전**을 뜻합니다.

처음부터 많은 기능을 넣기보다, 꼭 필요한 기능부터 만들어 직접 사용해 봅니다. 사용하면서 불편한 점을 확인한 뒤 필요한 기능을 조금씩 추가합니다.

## 3. 첫 번째 사용자는 누구인가요?

- 공부와 프로젝트 기록을 남기고 싶은 본인
- 여러 컴퓨터에서 같은 기록을 확인하고 싶은 사람
- 복잡한 설정 없이 간단하게 기록하고 검색하고 싶은 사람

첫 버전은 개인용으로 만듭니다. 다른 사람이 회원가입해서 사용하는 기능은 포함하지 않습니다.

## 4. MVP의 목표

BuildLog의 첫 번째 버전에서는 다음 세 가지를 할 수 있어야 합니다.

1. 오늘 공부한 내용을 기록하고 다시 볼 수 있다.
2. 앞으로 할 일을 적고 완료 여부를 확인할 수 있다.
3. 오류와 해결 과정을 모아두고 비슷한 문제가 생겼을 때 찾아볼 수 있다.

## 5. 필요한 화면

### 로그인 화면

본인만 BuildLog에 들어갈 수 있도록 로그인합니다. 첫 버전에는 회원가입과 여러 사용자 관리 기능을 넣지 않습니다.

### 홈 화면

로그인 후 가장 먼저 보는 화면입니다. `학습 기록`, `할 일`, `오류 기록` 메뉴로 쉽게 이동할 수 있습니다. 아직 끝내지 않은 할 일과 해결하지 못한 오류도 한눈에 확인할 수 있습니다.

### 학습 기록 화면

오늘 공부한 내용을 제목과 본문으로 작성합니다. 저장한 기록을 목록에서 보고, 하나를 선택해 자세히 읽을 수 있습니다.

### 할 일 화면

앞으로 공부할 내용이나 프로젝트에서 해야 할 일을 적습니다. 일을 끝내면 체크하고, 완료한 일과 남은 일을 구분해서 볼 수 있습니다.

예시:

- 저장 버튼 만들기
- 파이썬 복습하기

### 오류 기록 화면

공부나 개발 중 만난 오류를 따로 기록합니다. 아직 해결하지 못한 오류도 저장할 수 있습니다. 나중에 해결하면 해결 방법을 추가하고 상태를 `해결 완료`로 바꿉니다.

## 6. 핵심 기능

### 공통 기능

- 본인 계정으로 로그인하기
- 작성한 기록 저장하기
- 저장한 기록 목록 보기
- 기록 자세히 보기
- 기록 수정하기
- 필요 없는 기록 삭제하기
- 제목과 내용으로 기록 검색하기
- PC와 휴대폰 화면에서 편하게 사용하기

### 학습 기록

학습 기록에는 다음 내용을 저장합니다.

- 제목
- 공부한 내용
- 작성일
- 마지막 수정일

### 할 일

할 일에는 다음 내용을 저장합니다.

- 할 일 내용
- 완료 여부
- 작성일
- 완료일

완료하지 않은 일을 먼저 볼 수 있고, 체크한 일은 완료 목록에서 확인할 수 있어야 합니다.

### 오류 기록

오류 기록에는 다음 내용을 저장합니다.

- 오류 제목
- 오류 내용 또는 화면에 나온 메시지
- 오류가 생긴 상황
- 해결 여부
- 해결 방법
- 작성일
- 마지막 수정일

해결 방법은 처음부터 입력하지 않아도 됩니다. 해결하지 못한 상태로 저장한 뒤 나중에 추가할 수 있습니다.

## 7. 기본 사용 흐름

### 공부한 내용을 남길 때

1. 로그인한다.
2. `학습 기록`으로 이동한다.
3. 제목과 내용을 작성한다.
4. 저장한다.
5. 목록에서 저장된 기록을 확인한다.

### 할 일을 관리할 때

1. `할 일`로 이동한다.
2. 새로운 할 일을 입력한다.
3. 일을 끝낸 뒤 완료 체크를 한다.
4. 완료한 일과 남은 일을 구분해서 확인한다.

### 오류를 기록할 때

1. `오류 기록`으로 이동한다.
2. 오류 제목, 내용, 발생 상황을 작성한다.
3. 해결하지 못했더라도 먼저 저장한다.
4. 해결한 뒤 기록을 다시 열어 해결 방법을 작성한다.
5. 상태를 `해결 완료`로 바꾼다.

### 예전 기록을 찾을 때

1. 찾고 싶은 단어를 검색창에 입력한다.
2. 제목이나 내용에 해당 단어가 포함된 기록을 확인한다.
3. 원하는 기록을 열어 다시 읽는다.

## 8. 첫 버전에서 제외할 기능

다음 기능은 유용할 수 있지만 첫 버전에는 넣지 않습니다.

- 누구나 가입할 수 있는 회원가입 기능
- 여러 사용자의 계정 관리
- 다른 사람과 기록 공유하기
- 댓글과 좋아요
- 이미지와 파일 첨부
- 복잡한 통계와 그래프
- AI가 내용을 자동으로 요약하거나 분류하는 기능
- 알림과 일정 연동

이 기능들은 BuildLog를 실제로 사용해 본 뒤 필요성이 확인되면 추가합니다.

## 9. 데이터 보관 원칙

- 실제 서비스의 기록은 Supabase의 PostgreSQL 데이터베이스에 저장합니다.
- 로컬 개발과 자동 테스트에서는 SQLite 3 데이터베이스를 사용합니다.
- SQLite 3에서 확인한 기능은 Supabase에서도 같은 결과로 동작해야 합니다.
- 다른 컴퓨터에서도 로그인하면 같은 기록을 볼 수 있어야 합니다.
- 로그인하지 않은 사람은 기록을 볼 수 없어야 합니다.
- 비밀번호 같은 중요한 정보는 코드나 공개 저장소에 직접 적지 않습니다.

## 10. MVP 완료 기준

다음 항목이 모두 가능하면 첫 번째 MVP가 완성된 것으로 봅니다.

- 본인 계정으로 로그인할 수 있다.
- 학습 기록을 작성하고 저장·조회·수정·삭제할 수 있다.
- 할 일을 추가하고 완료 여부를 바꿀 수 있다.
- 완료한 일과 남은 일을 구분해서 볼 수 있다.
- 해결 전인 오류를 저장할 수 있다.
- 오류에 해결 방법을 추가하고 해결 완료로 바꿀 수 있다.
- 제목과 내용으로 필요한 기록을 검색할 수 있다.
- 여러 컴퓨터에서 같은 데이터를 확인할 수 있다.
- PC와 휴대폰에서 주요 기능을 불편 없이 사용할 수 있다.

## 11. 나중에 고려할 기능

MVP를 사용한 뒤 필요하면 다음 기능을 검토합니다.

- 태그와 카테고리
- 즐겨찾기
- 날짜별 학습 기록 모아보기
- 학습 시간과 완료한 일 통계
- 이미지와 파일 첨부
- 데이터 내보내기와 백업
- AI를 이용한 요약과 비슷한 오류 추천
- 여러 사용자 가입과 기록 공유
